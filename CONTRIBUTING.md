# Contributing

DOPER is a research code release, and it is not accepting pull requests at this time.

Bug reports and questions are welcome as GitHub issues. Include the DOPER version or commit, the
command you ran, and the full error output. Participation is governed by the
[Code of Conduct](CODE_OF_CONDUCT.md).

Do not report security vulnerabilities in issues; follow [SECURITY.md](SECURITY.md) instead.
